# 網頁開發學習紀錄

以 note-vite 本身為實際應用目標，從 HTML/CSS 基礎學到 React + TypeScript + Vite，能獨立建置、維護與擴充這個網站。

## 學習路線

| 階段 | 主題 |
|------|------|
| 階段一 | HTML 語意結構 → CSS 盒模型 / Flexbox → CSS Grid / Responsive |
| 階段二 | TypeScript 型別基礎 → 函式與泛型 → TS + React 整合 |
| 階段三 | React 元件與 JSX → Hooks → React Router |
| 階段四 | Vite 建置與部署 → 元件抽象與資料分離 |

---

> 每次 `webstart` 學習結束後，Claude 會協助整理教學重點與習題，存至此區域。
